# 演示拍摄方案：待真实素材

尚未录制或发布真实接续视频。`threadport ui --demo --no-open` 只展示合成任务，不计入用户激活。视频必须在通过认证的候选包上录制，使用获准公开的隔离项目与日志。

30–45 秒分镜：0–8 秒搜索昨天的任务；8–16 秒展示最后失败及人工约束；16–25 秒选择目标 Agent 并滚动完整预览；25–35 秒复制固定 UUID 命令，真实呈现终端确认；35–45 秒展示目标 Agent 在正确目录完成预设下一步的证据。

不能把终端确认剪成浏览器一键启动，不能用字幕把 unknown 改为“已通过”。录制前检查画面中的目录、会话正文、终端 token、账号和通知。演示素材不用于替代外部用户记录；未经许可不发布他人内容。

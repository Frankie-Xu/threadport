## 重要技术注意事项

- `src/adapters/common.ts` 的 portable 处理目前只覆盖使用公共 assembler 的适配器。
- `src/targets.ts` 使用 `which`，目前主要适配 Unix/macOS。
- `suggestedLaunch()` 返回的 `--prompt-file` 参数尚未经过各 Agent CLI 的真实 contract test 验证。
- `handoff` JSON envelope 当前是 CLI 内部对象，尚未有正式 schema。
- `atomicWrite` 对单个文件是原子的，但 JSON 和 Markdown 两个文件之间不是事务性提交。
- `npm audit --omit=dev`：0 vulnerabilities。
- 完整 `npm audit`：Vitest/@vitest/mocker 2 个 moderate，升级可能涉及 Vitest 主版本变化。
